# Tessa Vujovic

Tessa's portfolio, built with HTML and CSS. The published site lives in `docs/`.

## Local development

With Node.js installed, run:

```sh
npm run dev
```

Open http://localhost:3001. Changes in `docs/` automatically reload the browser.
Set `PORT` to use another port. No package installation is needed.

## Publishing

GitHub Pages serves the `docs/` directory. The development server injects its
reload script locally; production has no JavaScript dependencies.
